# Corewar-Project

Hi ! I'm Stanislas Gaumain, an Epitech's student, I'm redoing the corewar project in C from scratch.

I'll make it without any AI, which means that no coding, no review, no comments or research will be done using AI.
This project is meant to help me understand the corewar better and to maintain my knowledge of the language C, but also and on top of everything, to enjoy myself because i love coding.

I'll try to have a clean repo where everyone can see the progress and tell me what they think about the code or the architecture. I'm open to tips if this can help me have a cleaner way of coding or if you find things in my repo that are bad or simply that could be better.

The first commit consists of the base of the project with the Makefile, main.c, some simple functions for error handling and for the "-h" to work, a base for the tests, some exemple files to test the program (given by Epitech) and all the necessary infos for the corewar in the includes (given by Epitech as well).

The commit norm will have this form: "action(scope): details" (except for the first commit).
